안녕하세요, **이춘우**입니다. SpringRain이라는 이름으로 활동합니다.

서버 운영으로 경력을 시작해, 실제 서비스의 백엔드와 클라우드 인프라를 함께 개발해 왔습니다. 현재는 예스씨엔씨에서 **Python과 FastAPI 기반 클라우드 관리 플랫폼**을 개발합니다.

안정적인 API, 추적 가능한 비동기 작업, 반복 업무를 줄이는 운영 도구를 만드는 데 집중합니다.

[경력과 기술 보기](/about/) · [프로젝트 보기](/projects/) · [GitHub](https://github.com/chunwoolee-dev)

## 집중하는 영역

| 영역 | 주요 경험 |
| :--- | :--- |
| 백엔드 개발 | FastAPI · NestJS · Express, REST API, 데이터 모델링 |
| 비동기 처리 | RabbitMQ 기반 Job 처리, 리소스 자동 수집, WebSocket |

## 최근 프로젝트

### XCMP Backend

**2026.07–현재 · 예스씨엔씨**

XenServer 기반 클라우드 관리 플랫폼입니다. 서버·풀·가상머신·네트워크·스토리지 API, RabbitMQ 기반 비동기 작업, 운영 메트릭 수집을 개발합니다.

### PCMP Backend

**2025.12–현재 · 예스씨엔씨**

Proxmox 기반 클라우드 관리 플랫폼입니다. 가상머신 설정과 고가용성, 리소스 동기화, 보고서와 VMware 마이그레이션 기능을 개발합니다.

### GPU Allocation

**2025.09–2025.11 · 예스씨엔씨**

Linux 서버에서 부서와 사용자 그룹별 NVIDIA GPU 접근 권한을 관리하는 운영 CLI와 자동화 절차를 구현했습니다.
